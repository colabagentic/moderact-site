What I measure

Counts, not screenshots.

Visibility: the share of answers that name you, per engine, across many runs on several days.

Who else: the businesses that get named for the same questions.

Sources: the pages the engines cite while answering, so we know where a mention has to appear.

A screenshot is not a measurement. One answer changes from run to run and from day to day, so every number is a count across runs, with its uncertainty stated.

How it works
